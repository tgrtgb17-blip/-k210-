
# STM32-FreeRTOS-VisionArm

> 基于 STM32F10x 与 FreeRTOS 的视觉引导舵机机械臂控制固件

## 项目简介

STM32-FreeRTOS-VisionArm 是一个面向桌面级视觉机械臂的开源控制固件。项目运行于 STM32F10x 系列 MCU，采用 FreeRTOS 进行多任务调度，通过串口接收上位机或视觉模块发送的目标坐标与角度信息，结合逆运动学解算，驱动多路 SG90 舵机完成目标跟随、夹取与放置动作。系统支持 OLED 状态显示、按键启停、颜色分拣以及舵机平滑插值控制，适合作为嵌入式实时系统、机器人控制与机电一体化教学的开源参考项目。

## 核心特性

- **多任务实时调度**：基于 FreeRTOS，任务间通过队列、信号量与互斥锁进行通信与同步。
- **视觉数据串口接收**：使用 USART + DMA + IDLE 中断接收定长数据帧，降低 CPU 占用。
- **逆运动学解算**：根据目标坐标与姿态角计算各关节舵机角度，支持跟随与抓取两种模式。
- **舵机平滑控制**：对目标角度进行逐步插值，避免舵机突变，提升机械臂运动平稳性。
- **夹取与放置流程**：到达目标位置后控制夹爪完成抓取，并根据颜色标识执行放置动作。
- **OLED 状态显示**：实时显示关节角度或运行状态，便于调试与监控。
- **按键启停控制**：通过外部中断实现系统运行/停止切换，并带简易软件消抖。
- **模块化代码结构**：任务、驱动与算法分层清晰，便于移植和二次开发。

## 系统架构

| 任务/模块 | 功能说明 |
|---|---|
| `Task_UA` | 接收串口视觉数据，解析坐标与颜色，调用逆运动学算法 |
| `Task_SET_SG90` | 接收目标角度，平滑驱动舵机，触发夹取动作 |
| `Task_Mount` | 执行放置动作序列，完成后恢复跟随模式 |
| `Task_OLED` | 显示关节角度或系统状态 |
| `EXTI15_10_IRQHandler` | 按键中断，切换运行状态 |
| `USART1_IRQHandler` | DMA + IDLE 中断接收视觉数据帧 |

## 硬件平台

- MCU：STM32F10x 系列（如 STM32F103）
- 舵机：SG90 及兼容 PWM 舵机，最多 6 路
- 显示：I2C/SPI OLED 模块
- 通信：USART1，连接视觉模块或上位机
- 输入：外部按键，用于启停控制
- 开发库：STM32 标准外设库 + FreeRTOS

## 通信协议示例

视觉数据帧长度固定为 10 字节：

| 字节 | 内容 |
|---|---|
| 0 | 帧头 0x31 |
| 1 | 帧头 0x51 |
| 2 | 颜色标识（如 `'R'` / `'B'`） |
| 3-4 | 目标 X 坐标（int16） |
| 5-6 | 目标 Y 坐标（int16） |
| 7-8 | 目标姿态角（int16） |
| 9 | 帧尾 0x5B |

> 协议可根据实际视觉模块或上位机进行修改。

## 快速开始

1. 使用 Keil MDK 或 STM32CubeIDE 打开工程。
2. 根据实际机械臂尺寸修改 `ik.c` / `ik90.c` 中的逆运动学参数。
3. 根据舵机安装方向与限位调整 `SG90_set_angle()` 中的角度映射。
4. 编译下载至 STM32F10x 开发板。
5. 连接 OLED、舵机、按键与串口视觉模块。
6. 上电后按下按键启动系统，通过串口发送目标数据即可测试。
